# TicketPulse Mobile

Expo React Native app for TicketPulse organizers and crew.

## MVP Scope

- Organizer sign-in handoff
- Event operations dashboard
- Full-screen QR scanner
- Valid, duplicate, and invalid scan states
- Haptic and sound feedback
- Recent scan history

## Development

```bash
cd mobile
npm install
npm run start
```

The app points at `https://ticketpulse.tech` by default. For local API testing, update `extra.apiBaseUrl` in `app.json`.
